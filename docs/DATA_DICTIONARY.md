# Data dictionary

This file defines every column and every JSON field in the Haishoku compilation. The values were read from the Seigensha edition of Sanzo Wada’s color dictionary. How they were read is in [METHODOLOGY.md](METHODOLOGY.md).

Three files hold the same colors and combinations:

| File | Shape |
| --- | --- |
| [`data/wada_colors_and_combinations.json`](../data/wada_colors_and_combinations.json) | Canonical. Nested, and the only file with per-swatch sample, OCR score, and delta E. |
| [`data/colors.csv`](../data/colors.csv) | One row per named color. Convenient in a spreadsheet. |
| [`data/combinations.csv`](../data/combinations.csv) | One row per combination, with up to four color slots. |

Derived files under [`data/derived/`](../data/derived/) repeat `display_hex` (and, for the CMYK swatch file, the printed ink values) for design tools. They are generated by `scripts/generate_derived.py`.

## Which value to use

| Decision | Field |
| --- | --- |
| A color on a screen, in CSS, in Figma, in Canva | `display_hex` |
| The scan before white balance, for auditing the photograph | `scan_hex` or `scan_rgb` |
| The ink percentages printed in the book | `c`, `m`, `y`, `k` |
| A rough RGB picture of those ink percentages | `hex_cmyk` |
| The color measured on a particular combination’s swatch, before matching | `page_sample_hex` |

`display_hex` is the reference swatch, white-balanced so the paper reads as white. It is the recommended screen color. It is a photograph of ink, so it is approximate. `hex_cmyk` is a direct arithmetic conversion and runs more saturated than the book.

## Identifiers

- **Color id** is 1 through 159, in the order of the reference swatches at the back of the book.
- **Combination number** is 1 through 348, in the order the combinations are printed. The CSV writes it zero-padded (`001`). The JSON stores an integer.
- **Two colors** are numbers 1–120, two per page, pages 28–87.
- **Three colors** are numbers 121–240, two per page, pages 90–149.
- **Four colors** are numbers 241–348, one per page, pages 152–259.
- **Book order** is left to right for two and three colors. Four-color plates are printed as a cross and are stored top, left, right, bottom.

### Names

`name` is the English name printed in the Seigensha edition. Spellings that differ from later usage are kept: Cerulian Blue, Antwarp Blue, Vandar Poel's Blue, Pale King's Blue, Hay's Russet, Vistoris Lake, Kronbergs Green. Two names contain a slash because the book prints them that way: Mars Brown/Tobacco, Deep Violet/Plumbeous.

Four colors are variants of two printed names. `base` is the shared name; `name` keeps them distinct.

| id | name | base | display_hex |
| --- | --- | --- | --- |
| 12 | Eugenia Red (variant a) | Eugenia Red | `#E6634F` |
| 13 | Eugenia Red (variant b) | Eugenia Red | `#DE5556` |
| 134 | Grayish Lavender (variant a) | Grayish Lavender | `#CBBFE7` |
| 135 | Grayish Lavender (variant b) | Grayish Lavender | `#CBB6C2` |

Where a combination uses one of these, its `notes` say which variant the swatch matched.

Japanese names are not in this release.

## `colors.csv`

159 data rows, plus a header. UTF-8, no byte-order mark, Windows-style line endings as published.

| Column | Type | Definition |
| --- | --- | --- |
| `id` | integer | Color number, 1–159. |
| `name` | text | English name as printed. Unique. |
| `c` | integer | Cyan, 0–100, as printed. |
| `m` | integer | Magenta, 0–100, as printed. |
| `y` | integer | Yellow, 0–100, as printed. |
| `k` | integer | Black, 0–100, as printed. |
| `hex_cmyk` | hex | Naive CMYK → RGB. Uppercase `#RRGGBB`. |
| `scan_hex` | hex | Raw scanned color of the reference swatch. |
| `display_hex` | hex | White-balanced reference swatch. Recommended for screens. |
| `ref_page` | integer | Page of that reference swatch in the scan, 285–351. |
| `combo_count` | integer | Number of combinations that include this color. Equal to the number of entries in `appears_in`. |
| `appears_in` | text | Combination numbers, ascending, space-separated, each written with three digits (`176 227 273`). |
| `note` | text | Empty for 158 colors. For id 19, Etruscan Red: `K corrected 0->6 (reference swatch page prints K6; the index table prints K0)`. |

Example, color 1:

```text
id,name,c,m,y,k,hex_cmyk,scan_hex,display_hex,ref_page,combo_count,appears_in,note
1,Hermosa Pink,0,30,6,0,#FFB2F0,#CEACC2,#FACDDE,285,3,176 227 273,
```

## `combinations.csv`

348 data rows, plus a header. Same encoding and line endings as the color file.

| Column | Type | Definition |
| --- | --- | --- |
| `number` | text | Combination number, three digits. |
| `size` | integer | 2, 3, or 4. |
| `page` | integer | Page in the scan. See the ranges above. |
| `color_1` | text | Name of the first color in book order. |
| `color_2` | text | Name of the second color. |
| `color_3` | text | Third color, or empty when `size` is 2. |
| `color_4` | text | Fourth color, or empty when `size` is 2 or 3. |
| `display_hex_1` … `display_hex_4` | hex or empty | `display_hex` for that slot. Empty when the slot is unused. |
| `hex_cmyk_1` … `hex_cmyk_4` | hex or empty | `hex_cmyk` for that slot. Empty when the slot is unused. |
| `positions` | text | `left/right`, `left/middle/right`, or `top/left/right/bottom`. The words line up with `color_1` … `color_4`. |
| `confidence` | text | `verified-visual` on every row in version 1.0.0. |
| `notes` | text | Confirmation note. Typical form: `back-index (OCR) confirms 2/2`. Variant rows add `variant picked by swatch color: …`. |

Example, combination 001:

```text
number,size,page,color_1,color_2,color_3,color_4,display_hex_1,display_hex_2,...
001,2,28,English Red,Cerulian Blue,,,#E45B1E,#1C93B2,,,#DE4500,#29BDAD,,,left/right,verified-visual,back-index (OCR) confirms 2/2
```

`confirms 2/2` means the OCR of the back index contained both colors of this pair. A note such as `confirms 3/4` means the index OCR recovered three of the four names. The missing names are index-OCR misses. They are not unresolved colors. See the methodology.

## JSON

Top-level keys: `meta`, `colors`, `combinations`.

### `meta`

| Field | Definition |
| --- | --- |
| `source` | One-line description of the edition and the fact that values were read from page images. |
| `hex_fields` | A short definition of `display_hex`, `scan_hex`, and `hex_cmyk`. |
| `method` | Matching and cross-check summary. |
| `positions` | The book-order rule. |

### Color object

| Field | Type | Definition |
| --- | --- | --- |
| `id` | integer | 1–159. |
| `name` | string | Printed English name. |
| `base` | string | `name`, with a trailing `(variant a)` or `(variant b)` removed. Equal to `name` for the other 155 colors. |
| `c`, `m`, `y`, `k` | integer | Printed ink percentages, 0–100. |
| `hex_cmyk` | string | Naive CMYK → RGB, `#RRGGBB`. |
| `scan_rgb` | array of 3 integers | Raw scan as `[R, G, B]`, each 0–255. Equals `scan_hex`. |
| `scan_hex` | string | Raw scan as hex. |
| `display_hex` | string | White-balanced hex. Recommended for screens. |
| `ref_page` | integer | Reference-swatch page, 285–351. |
| `appears_in` | array of integers | Combination numbers, ascending. The CSV’s `combo_count` is `appears_in.length`. |
| `note` | string | Empty, or the Etruscan Red K6 note. |

There is no `combo_count` field in the JSON. Use the length of `appears_in`.

### Combination object

| Field | Type | Definition |
| --- | --- | --- |
| `number` | integer | 1–348. |
| `size` | integer | 2, 3, or 4. Equal to `colors.length`. |
| `page` | integer | Page in the scan. |
| `positions` | array of strings | Same words as the CSV `positions` column, already split. |
| `colors` | array | One object per swatch, in book order. |
| `confidence` | string | `verified-visual`. |
| `notes` | string | Same text as the CSV `notes` column. |

### Slot object (`combinations[].colors[]`)

| Field | Type | Definition |
| --- | --- | --- |
| `id` | integer | Reference color id. Always a color that exists. No combination repeats an id. |
| `name` | string | Copy of that color’s name. |
| `display_hex` | string | Copy of that color’s `display_hex`. |
| `scan_hex` | string | Copy of that color’s `scan_hex`. |
| `hex_cmyk` | string | Copy of that color’s `hex_cmyk`. |
| `page_sample_hex` | string | Hex sampled from this swatch on the combination page. It is allowed to differ from `scan_hex` and `display_hex`; those come from the reference page. |
| `label_ocr_match` | number | Similarity from 0 to 1 between the OCR string of the printed English label and `name`. A value of 1 is an exact string match. A lower value usually means punctuation or a short word was clipped. It does not, on its own, mean the slot was reassigned. |
| `delta_e` | number | CIEDE2000 between the page swatch and the reference swatch of the matched color. In this release the values run from 0.3 to 10.1. |

The copies on the slot (`name`, `display_hex`, `scan_hex`, `hex_cmyk`) match the color record. Validation fails if they drift.

## Derived files

| File | Contents |
| --- | --- |
| `colors.css` | `:root { --haishoku-<slug>: <display_hex>; }` for all 159 colors. |
| `combinations.css` | `.haishoku-combo-001 { --haishoku-1: …; }` in book order, up to `--haishoku-4`. |
| `colors.scss` | `$haishoku-colors` map, slug to `display_hex`. |
| `tailwind.colors.json` | Object of slug → `display_hex`, meant to live under `theme.extend.colors.haishoku`. |
| `display-hex.json` | Object of printed name → `display_hex`, in reference order. |
| `haishoku.gpl` | GIMP palette. RGB bytes of `display_hex`, name after a tab. |
| `haishoku-rgb.ase` | Adobe Swatch Exchange. Group “All colors”, then “Combo 001” … “Combo 348”, RGB from `display_hex`. |
| `haishoku-cmyk.ase` | The same groups, with the printed CMYK percentages scaled to 0–1. |

Slugs are the printed name in lowercase, with apostrophes removed and every other run of non-alphanumeric characters turned into a single hyphen: `Vandar Poel's Blue` → `vandar-poels-blue`.

## Worked combination

Combination 176, page 117, three colors, left to right:

| Position | id | Name | display_hex |
| --- | --- | --- | --- |
| left | 116 | Calamine Blue | `#86D6DE` |
| middle | 1 | Hermosa Pink | `#FACDDE` |
| right | 43 | Seashell Pink | `#FEDFCF` |

A 60/30/10 use of this row would put Seashell Pink on the largest surface, Calamine Blue on the next, and Hermosa Pink on the small accents. The book itself prints the three swatches at the same size. The proportion is a choice you make when you apply it. More of that is in [USE_CASES.md](USE_CASES.md).
